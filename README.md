# Science Lab Simulator

An advanced, browser-based virtual science laboratory for students. The interface is designed as a calm, spacious digital lab with reusable simulation components.

## Included foundation
- Physics, Chemistry, Biology and Environmental Science tracks
- Interactive experiment workspace
- Real-time measurements and controls
- Observation recording
- Notebook and progress views
- Responsive layout
- GitHub Pages compatible, client-side architecture

## Initial simulations
- Ohm's Law
- Simple Pendulum
- Acid–Base Titration

The experiment catalogue is data-driven so additional curriculum practicals can be added without redesigning the application.
